READ THE METHOD

Explainable by design.

  1. 01
    Validate the activity data

    Require a student ID and eight numeric activity fields. Missing, negative, non-finite, or out-of-range values prevent scoring that row.

  2. 02
    Rank, then combine

    For each metric: average rank for ties ÷ valid cohort size × 100. The activity score is the weighted mean, rounded to two decimals before classification.

  3. 03
    Compare with a visible threshold

    The default is 50.2 / 100, an illustrative cutoff. It is an exploratory setting, not a validated educational standard.

Scores are relative to this upload: adding or removing records can change rankings. A longer session or more clicks does not necessarily mean deeper learning. No demographic, grade, or risk fields are used.

DATA QUALITY & PROVENANCE

Know the limits.

    About the public demo

    The 500 demo records are generated examples, not real students. Their labels come from the same activity-scoring rule, so agreement is expected and is not predictive accuracy.

    The original uploaded workbook is excluded from this public project. Use Upload dataset to analyse a compatible file in your current browser view. The app does not save uploaded files to disk.

    Scores are relative to the uploaded cohort and should be interpreted with context.

    Use this dashboard for exploratory analysis and supportive conversations. Results should not determine grades, discipline, or access to education.
